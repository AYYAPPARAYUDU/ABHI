# Contradictions, Constraints & Technical Risks Analysis

## 1. Identified Contradictions & Tensions

| Tension / Contradiction | Description | Technical Resolution Strategy |
| :--- | :--- | :--- |
| **Simultaneous Multimodal AI vs. 8 GB VRAM Ceiling** | Running 8B LLM (~5.2 GB), Whisper STT (~1 GB), Vision VLM (~2-4 GB), and Diffusion Image/Video Gen (~5-8 GB) simultaneously exceeds the physical 8 GB VRAM limit. | **Tiered Time-Multiplexing & Offload Engine:**<br>• Core perception (MediaPipe, Silero VAD, Audio Capture) runs on CPU/iGPU.<br>• STT & TTS use highly quantized lightweight INT8/ONNX models (shared ~1 GB).<br>• Primary LLM stays resident during conversational agent cycles.<br>• When heavy diffusion (image/video generation) is initiated, LLM state is dynamically offloaded to system RAM (24 GB available) and swapped back upon generation completion. |
| **Autonomous Mouse/Keyboard Automation vs. Active Human Work** | If the AI moves the cursor while the user is actively working, it creates input collisions, focus loss, and workflow disruption. | **Input Arbitration & Notification Shield:**<br>• Explicit automation mode banner in UI with global pause/resume hotkey.<br>• Prioritize background automation (Direct Win32 API, PowerShell, Browser CDP) over intrusive physical cursor clicks wherever supported.<br>• Automatic human-motion override: If the user touches the physical mouse during automation, agent pauses immediately and asks to yield or continue. |
| **Local Video Generation vs. Laptop Inference Realities** | State-of-the-art video models (HunyuanVideo, Wan2.1) require 24GB+ VRAM. Attempting unquantized video generation locally is technically impractical. | **Quantized Modular Video Micro-Pipeline:**<br>• Use optimized INT8/GGUF models (LTX-Video-GGUF / SVD-XT quantized / AnimateDiff LCM).<br>• Keep video generation as an on-demand, non-blocking asynchronous background task with clear progress reporting and resolution caps (e.g. 512x512, 2-4 seconds). |
| **Python 3.14.6 Global Environment vs. C++/CUDA Wheels** | Python 3.14 was recently released; PyTorch CUDA wheels, TensorRT, and CTranslate2 frequently lack pre-built binaries for 3.14 on Windows. | **Dedicated Python 3.11 / 3.12 Virtual Environment:**<br>• Create an isolated local virtual environment running Python 3.11 or 3.12 for the AI backend using `uv` / standalone runtime to ensure 100% stable precompiled CUDA 13.1 acceleration. |
| **Rich Three.js 3D Rendering vs. Low Background CPU/GPU Budget** | A complex 3D Three.js animation running continuously at 60 FPS can consume 10-20% GPU and battery on a laptop. | **Adaptive Frame Rate & Event-Driven Rendering:**<br>• Implement `requestAnimationFrame` throttling: run full 60 FPS when active user interaction or voice speech occurs.<br>• Automatically throttle down to 10–15 FPS or pause render loop entirely when the application is idle or tab is hidden (`document.hidden`). |
